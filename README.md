# Car Service Center Application

## Overview

This application serves as a car service center management system, allowing users to book services, manage appointments, and access service history.

## Front-End Server

The front-end of this application is built using Angular. It provides a dynamic and responsive user interface, allowing users to interact with the application seamlessly. The front-end communicates with the back-end server through RESTful APIs to fetch and display data.

## Back-End Server

The back-end server is built using Express and MongoDB. It handles all server-side logic, including managing user requests, processing data, and interacting with the database. The back-end provides RESTful API endpoints that the front-end utilizes to perform operations like booking services and retrieving service history.

### Prerequisites

- Angular CLI (version X.X.X or higher)
- MongoDB (running instance)
